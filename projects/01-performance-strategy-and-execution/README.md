# 1. Performance Strategy & Execution

**Context:** Enterprise government client applications (client details confidential)
**Role:** Performance Test Engineer · **Period:** Jan 2021 – Present
**Tools:** Apache JMeter, NeoLoad, SQL

## Problem
Large, user-facing applications needed confidence they would stay stable and fast under peak traffic, with a clear view of cost and effort per sprint.

## What I did
- **Strategy:** Designed end-to-end performance test strategies covering scope, workload models, environments, entry/exit criteria and risks.
- **Requirements & estimation:** Gathered non-functional requirements from documents and direct conversations with client SMEs, then used structured methods to estimate person-hours, time and cost per sprint.
- **Scripting:** Built advanced JMeter and NeoLoad scripts simulating complex user behaviour across Web, API and database protocols.
- **Load & stress:** Executed high-scale tests simulating **10,000+ concurrent users** to validate stability and support capacity planning for peak traffic.

## Results
- **78+ critical bottlenecks** identified and resolved
- **~30% speed improvement**
- Capacity planning inputs for peak-traffic scenarios

## Approach in brief
1. Requirements and workload modelling
2. Estimation and planning
3. Script development and data preparation
4. Baseline, load, stress and soak runs
5. Analysis, tuning recommendations, retest
6. Sign-off and capacity report
