# 3. Observability & Dashboards

**Role:** Performance Test Engineer (commercial project) · **Tools:** Grafana, InfluxDB, PowerBI, Tableau

## Problem
Stakeholders couldn't see test results in real time, and finding the source of an issue took too long.

## What I did
- Integrated custom **Grafana dashboards with InfluxDB** for live test visibility.
- Built **15+ reusable PowerBI/Tableau visualisations** for performance KPIs.
- Led a technical session for **150 stakeholders** on using them.

## Results
- **40% reduction in issue identification time**
