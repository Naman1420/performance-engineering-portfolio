# 4. Data Integrity Automation

**Role:** Performance Test Engineer (commercial project) · **Tools:** Python, SQL

## Problem
Validating data consistency across distributed systems was manual, slow and limited in coverage.

## What I did
Developed automated scripts that validate data integrity across systems (row counts, key completeness, field-level mismatches).

## Results
- **60% increase in test coverage**
- **35 hours/week** of manual validation eliminated
